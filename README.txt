PROBAR
Abre index.html en un navegador compatible. Para usarla como aplicación instalable, publícala en un sitio HTTPS.

BORRAR VENTAS DE PRUEBA
Entra a Reportes y cálculos > Historial de ventas > Borrar. Confirma la operación. El sistema elimina esa venta, recalcula reportes y devuelve las unidades vendidas al inventario si el producto todavía existe. No elimina los productos.

IMPORTANTE
Los datos se guardan en el almacenamiento local del navegador de ese dispositivo. Esta versión no sincroniza información entre dispositivos. El inicio de sesión es básico y no debe usarse para datos sensibles.
